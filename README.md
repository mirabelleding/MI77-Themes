# MI77-Themes

A collection of themes and configurations for development environments, by MI77-LAB.

- **[VS Code](./vscode/)** — Visual Studio Code themes.
- **[Terminal](./terminal/)** — Terminal prompts and color configurations for Bash.
  - **[MI77 Terminal Studio](https://mirabelleding.github.io/MI77-Themes/terminal/studio/)** — An interactive tool for customizing Bash prompts with live previews and ready-to-use configurations.
